# 21 — Glossary

| Term | Meaning |
|---|---|
| A0–A4 | Automation levels (see 00 §6) |
| Accession number | Unique study identifier issued by the Platform (format in 08) |
| ADT | HL7 Admit/Discharge/Transfer messages from hospitals |
| AGD | Average glandular dose (mammography) |
| BCI | Bonakala Clinical Intelligence: all AI models and Hands |
| BDL | Bonakala Design Language |
| BHF / PCNS | Board of Healthcare Funders / Practice Code Numbering System |
| CMS | Council for Medical Schemes |
| COIDA | Compensation for Occupational Injuries and Diseases Act |
| CTDIvol / DLP | CT dose descriptors |
| DAP | Dose-area product (radiography/fluoroscopy) |
| DICOM | Digital Imaging and Communications in Medicine |
| DICOMweb | QIDO-RS, WADO-RS, STOW-RS web services for DICOM |
| DRL | Diagnostic Reference Level |
| DSP | Designated Service Provider (scheme network) |
| DSO | Days sales outstanding |
| Edge Gateway | Per-site appliance providing DICOM routing, worklist and offline continuity |
| eGFR | Estimated glomerular filtration rate (renal function; contrast safety) |
| ERA | Electronic remittance advice |
| FHIR | HL7 Fast Healthcare Interoperability Resources (R4) |
| Hand | An autonomous agent with a mandate and a leash (M20) |
| HPCSA | Health Professions Council of South Africa |
| Hub | Virtual reading pool (teleradiology) |
| ICD-10 | Diagnosis coding standard, mandatory on SA claims |
| ILO classification | International Labour Office classification of pneumoconiosis radiographs |
| IOD | Injury on duty (COIDA) |
| JV | Joint venture practice with multiple shareholder classes |
| Leash | Numeric and categorical limits on what a Hand may do without approval |
| Lens | Persona-level token override in BDL |
| MPPS | Modality Performed Procedure Step |
| MSO | Management Services Organisation |
| MWL | DICOM Modality Worklist |
| NHI | National Health Insurance |
| No-slip | The AI safety charter (12) |
| ODMWA | Occupational Diseases in Mines and Works Act |
| PACS | Picture Archiving and Communication System (M09) |
| PMB | Prescribed Minimum Benefit |
| POPIA | Protection of Personal Information Act |
| Practice | A clinical legal entity with a practice number (tenant) |
| Provenance | Model id, version, confidence, inputs and acceptance record attached to any AI output |
| RAF | Road Accident Fund |
| RDSR | Radiation Dose Structured Report |
| RIS | Radiology Information System (M04–M08, M12–M13 collectively) |
| RPO | Radiation Protection Officer |
| SAHPRA | South African Health Products Regulatory Authority |
| SaMD | Software as a Medical Device |
| SAST | South African Standard Time (UTC+2) |
| Slip | An AI output reaching a downstream party without its verification tier (00 §7) |
| SR | DICOM Structured Report |
| Switch | Electronic claims intermediary between providers and funders |
| Tariff code | Procedure billing code used on SA claims |
| Window / Level | BDL's interface density and emphasis control |
